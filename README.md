# Pizza Sales and Customer Behavior Analysis : 

## Project Overview : 

This project analyzes pizza sales data using MySQL and Microsoft Excel to uncover revenue trends, customer purchasing behavior, product performance, and business opportunities. The project combines SQL-based business analysis with interactive Excel dashboards to support data-driven decision-making.

## Tools Used : 

* MySQL
* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Dashboard Design

## Dataset Overview : 

The dataset contains pizza sales transaction data including:

* Order ID
* Order Date
* Order Time
* Pizza Name
* Pizza Category
* Pizza Size
* Quantity
* Total Price

Additional helper columns created during analysis:

* Month
* Weekday
* Hour

## SQL Analysis : 

Performed 15 business-driven SQL analyses including:

* Total Revenue Analysis
* Total Orders Analysis
* Total Pizzas Sold Analysis
* Revenue by Category
* Revenue by Size
* Top & Bottom Performing Pizzas
* Revenue Contribution Analysis
* Weekday Revenue Analysis
* Order Volume by Hour
* Category Performance Comparison
* Revenue Ranking using Window Functions

### SQL Concepts Used : 

* Aggregate Functions

## Key Insights : 

* Classic pizzas generated the highest revenue, contributing approximately 27% of total revenue.
* Large-sized pizzas generated the highest revenue and quantity sold.
* Friday recorded the highest revenue among all weekdays.
* Revenue peaked in July while September and October recorded the lowest revenue levels.
* Peak order activity occurred during afternoon and evening hours.

## Business Recommendations : 

* Promote high-performing pizza categories.
* Optimize low-performing products.
* Focus marketing efforts on large-sized pizzas.
* Leverage high-revenue days through targeted promotions.
* Improve staffing and inventory management during peak hours.
